# Model artifacts

Trained files used at runtime (generated by `training/train_*.py`):

| File pattern | Used by |
|---|---|
| `{condition}_xgb.pkl` | XGBoost inference (all 3 diseases) |
| `{condition}_scaler.joblib` | Feature scaling |
| `{condition}_features.joblib` | Feature column order |
| `parkinsons_lstm.keras` | 7-day severity forecast (Parkinson's only) |

Asthma uses the same XGBoost pipeline as Parkinson's and Depression.

Regenerate everything:

```bash
cd ML
pip install -r requirements.txt
python datasets/generate.py
python training/train_parkinsons.py
python training/train_depression.py
python training/train_asthma.py
python training/train_lstm_parkinsons.py
```
